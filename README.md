## 🛠️ How to Update Daily Practice

1. **Jupyter Notebook (`daily_practice.ipynb`):**
   - Add a new cell block for the day.
   - Include problem statement, code solution, and time/space complexity notes.

2. **SQL Practice (`daily_practice.sql`):**
   - Append your daily query, notes, and test schema.

3. **Save, Commit, and Push:**
   ```bash
   git add .
   git commit -m "Day XX: Added [Topic/Problem Name] practice"
   git push origin main
   ```
