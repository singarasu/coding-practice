## 🛠️ How to Update Practice

1. **Jupyter Notebook (`coding_practice.ipynb`):**
   - Add a new cell block for your practice session.
   - Include problem statement, code solution, and time/space complexity notes.

2. **SQL Practice (`coding_practice.sql`):**
   - Append your query, notes, and test schema.

3. **Save, Commit, and Push:**
   ```bash
   git add .
   git commit -m "Add [Topic/Problem Name] practice"
   git push origin main
   ```
